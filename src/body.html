Rencana build Flutter

  • Peta 3D Three.js yang sama, ditanam via webview_flutter + JS bridge (Flutter Web: HtmlElementView).
  • Model satwa GLB/USDZ di model_viewer_plus, sekaligus mode AR.
  • QR → web dulu: tiap QR membuka URL ber-ID lokasi (app_links), jadi posisi diketahui tanpa GPS.
  • Data & dasbor Supabase: zona, fasilitas, jalur, jadwal, riwayat perubahan.
  • Kobi: LLM + data destinasi (RAG) lewat edge function, dengan aksi peta.

Posisi fasilitas ilustratif, mengikuti denah kasar. Harga, jadwal, dan status diambil dari sumber publik 2023–2026 dan harus diverifikasi pengelola sebelum dipakai.
